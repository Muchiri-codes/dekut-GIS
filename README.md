This is an app built on next js, tailwind css and typescript.
the navigation app is meant to aid visitors, students or Dedan kimathi university of technology staff move from one place to another within the school faster.

The app provides faster navigation by taking the start porint which could be input manually or set as the user's location and then destination and uses these two coordinates to find the best route depending on the means selected.

The app has 3 layers of maps, that is the normal open street map, satellite map and the OSM dark themed map.
